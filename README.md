# DDALAB Scoop bucket

```powershell
scoop bucket add sdraeger https://github.com/sdraeger/scoop-bucket
scoop install ddalab
```

`ddalab` is the command line of [DDALAB](https://github.com/sdraeger/DDALAB), delay differential analysis of EEG, iEEG
and other multichannel recordings. A workflow here writes `bucket/ddalab.json` from the latest DDALAB release every hour.
